SEO Bot

A small auditor for public websites. It crawls the pages you choose, scores the signals search engines actually read, and writes the fixes in plain language.

Run an audit Source

1. Crawl

Give it a public URL. It follows the sitemap and same-site links, and it skips private networks.

2. Score

Each page is checked for title, description, H1, canonical, viewport, alt text, Open Graph, and thin copy.

3. Fix

The report lists the highest-impact problems first. Optional drafts rewrite the title, description, and H1.
